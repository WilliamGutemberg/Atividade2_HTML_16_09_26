# Atividade2_HTML_16_09_26
Zootemberg — Zoológico Virtual

Sobre o projeto:

O Zootemberg é um zoológico virtual desenvolvido como atividade acadêmica utilizando somente HTML.

O site apresenta animais divididos nas categorias de mamíferos, répteis, aves e animais aquáticos. Cada categoria possui informações, imagens, áudios, vídeos e curiosidades sobre os animais.

O projeto também possui páginas de login, cadastro, agendamento de visita, sugestão de novos animais, informações sobre o zoológico e conservação das espécies.

Como abrir:

Para acessar o projeto, abra o arquivo "html/index.html" em um navegador.

Também é possível utilizar a extensão Live Server no Visual Studio Code.
